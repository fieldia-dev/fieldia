Under a strict Content-Security-Policy: scripts and styles run here only with this page’s nonce — no 'unsafe-inline', no 'unsafe-eval', nothing from another site. Fieldia is given the nonce and puts it on every style it adds. Refused by the policy so far: nothing. A real server sends the policy as a header and makes a new nonce for every response. fieldia.dev has no server of its own: there the policy is a meta tag in the page, and its nonce was written once, when the site was built — the same for every visitor.
