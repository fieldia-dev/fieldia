Fieldia’s one script tag under a strict Content-Security-Policy: the tag carries the page’s nonce, and fieldia.js puts it on every style and every part it adds. Refused by the policy so far: nothing. This browser refuses the style inside its own select boxes, as it does on any page under such a policy, with Fieldia or without: of its own so far. A real server sends the policy as a header and makes a new nonce for every response; fieldia.dev, a static site, has it as a meta tag with a nonce written once, the same for every visitor.
